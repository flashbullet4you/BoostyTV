# Boosty TV — MVP starter

Стартовый проект нативного приложения Android TV на Kotlin.

## Что уже есть
- экран каталога с демонстрационными карточками;
- навигация с D-pad / пульта;
- экран видеоплеера на Media3 ExoPlayer;
- тестовое MP4-видео;
- отдельный TV launcher entry point;
- структура для дальнейшего подключения Boosty.

## Важно
Сейчас каталог демонстрационный. Реальная авторизация Boosty, чтение закрытых публикаций и получение видеоссылок не реализованы: перед этим нужно подтвердить поддерживаемый способ доступа и проверить условия использования Boosty. Не вводите пароль Boosty в самодельные формы и не храните пароль или session cookies в исходниках.

## Требования
- JDK 17
- Android SDK / Android Studio (рекомендуется для установки SDK и запуска Android TV Emulator)
- Gradle wrapper можно создать через Android Studio или командой `gradle wrapper` при установленном Gradle.

## Запуск
1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Создайте Android TV Emulator (например, Android TV 1080p).
4. Запустите конфигурацию `app`.

Из терминала после настройки SDK:
```bash
gradle assembleDebug
```
APK ожидается в `app/build/outputs/apk/debug/app-debug.apk`.

## Тестовое видео
В демонстрации используется публичный тестовый MP4-файл. Для реального контента замените его только на поток, к которому у пользователя есть законный доступ.

## Версия 0.2.0 — пробный публичный каталог

- Каталог пытается загрузить до 30 публичных публикаций `miheevpavlov` через недокументированный внутренний endpoint `api.boosty.to`.
- Если получена прямая ссылка на видео, карточка запускает Media3; если нет — открывает страницу публикации в браузере.
- Доступ к закрытым публикациям и авторизация пока НЕ реализованы. Неофициальный API может измениться или отклонять запросы.
- На этом этапе не добавляйте пароли, cookies или токены в код/репозиторий. Для поддержки подписки потребуется отдельный безопасный поток авторизации и проверка условий Boosty.
